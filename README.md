# Your Portfolio Canvas

Personal portfolio for Nilesh Shete, built with React and TanStack Start.

## Development

You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm install
npm run dev
```

Set `VITE_SITE_URL` in your environment before deployment so canonical and social metadata use your public domain. See `.env.example`.

Build and run the production server with:

```sh
npm run build
npm start
```

Run the checks before publishing changes:

```sh
npm run lint
npm run test
npm run build
```
